# Wind decision dashboard

A decision-support pilot for evaluating the Great Britain wind generation
forecasts that were available before day-ahead electricity purchasing decisions
in January 2026.

The repository is organised as a small monorepo:

- `apps/api` — Python data pipeline and FastAPI service
- `apps/web` — React and Vite dashboard
- `docs` — product, data, and architecture decisions

Full setup, deployment, and methodology documentation will be added as the
implementation is completed.
